# Смена рядом

Сайт: https://kirill596.github.io/smena-ryadom/

## Партнёрская ссылка

Единственный редактируемый источник ссылки Самоката — `affiliateUrl` в
`public/config.json`. Сборка переносит настройки в `docs/config.json` и создаёт
резервные ссылки в HTML/JavaScript. После изменения настройки пересоберите релиз.
В браузере настройки также читаются из `config.json` без кеширования.

Все CTA Самоката в карточках, на страницах городов и в подробном предложении
ведут непосредственно на эту ссылку. Для Самоката устаревший `apply_url` из базы
не перекрывает общую настройку. Другие компании сохраняют прежнюю логику.
Тексты CTA и согласованное описание сохранены.

`subIdParam` оставлен пустым: подтверждённого имени параметра LEADS нет.
К ссылке Самоката не добавляются UTM, выбранный город или содержимое sessionStorage.
Существующая локальная атрибуция и настройки согласия на аналитику сохранены.

## Сборка и публикация

Нужны Git, Python 3 и Node.js для проверки/предпросмотра:

```sh
python scripts/build-release.py
node scripts/test-affiliate.mjs
node scripts/preview.mjs
```

Предпросмотр: http://localhost:8080/smena-ryadom/

Сборка обновляет `docs/` и `site-release.zip`. Закоммитьте оба результата вместе
с конфигурацией и скриптами. При push в `main` существующий GitHub Actions
`.github/workflows/deploy.yml` публикует `release/docs` из `site-release.zip`.
Настройки Pages менять не требуется.

## Почему сборка использует статический релиз

Опубликованная версия с админкой, фильтрами и согласованными текстами новее
исходников Next.js в этом репозитории. Скрипт воспроизводимо берёт архив из
коммита `160669389729adac2614cde9e6ac3f1da0acd481`, применяет ограниченные изменения
CTA, обновляет имя JS-файла по содержимому и все ссылки на него. Необходима
история Git с этим коммитом. Не используйте shallow clone без этой истории.

`npm run build` вызывает эту же сборку. Старый экспорт оставлен как
`npm run build:legacy` только для разработки: **его нельзя публиковать**, пока
исходники не синхронизированы с действующим сайтом, иначе исчезнут админка и
согласованные формулировки. Полное восстановление исходников — отдельная задача.

`docs/` — готовый статический сайт. Редактирование предложений по-прежнему
использует ранее подключённый backend; авторизация и её настройки не изменены.
